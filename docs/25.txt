# Document 25: Product Roadmap & Evolution Strategy

## Project Name

# Atlas

**Version:** MVP 1.0

---

# Purpose

This document defines the long-term evolution of Atlas from a hackathon project into a production-ready blockchain intelligence platform.

The roadmap exists to ensure every feature, architectural decision, and engineering effort contributes toward a single vision rather than becoming a collection of disconnected capabilities.

Atlas should be built incrementally.

Every release must provide immediate value while moving the platform toward its long-term objective.

---

# Product Vision

Atlas is building the operating system for blockchain intelligence.

Rather than becoming another blockchain explorer or analytics dashboard, Atlas becomes a continuously learning intelligence platform capable of:

* remembering every investigation
* understanding blockchain relationships
* coordinating AI agents
* detecting emerging threats
* explaining complex blockchain behavior
* assisting investigators through natural language
* operating autonomously when appropriate

Persistent memory is Atlas's competitive advantage.

---

# Product Principles

Every product decision should reinforce these principles:

* Evidence before assumptions
* AI enhances, never replaces, deterministic intelligence
* Every conclusion must be explainable
* Memory compounds in value over time
* Enterprise security is foundational
* Collaboration creates better intelligence
* Performance should scale with adoption
* Simplicity for users, sophistication internally

If a feature does not strengthen these principles, it should be reconsidered.

# Phase 1: Hackathon MVP

**Goal**

Demonstrate persistent agentic memory using CockroachDB on AWS while solving a real blockchain investigation problem.

This phase is focused on proving the core concept rather than maximizing features.

---

## MVP Features

Core capabilities:

* Wallet investigation
* Persistent investigation memory
* AI-powered investigation summaries
* Semantic memory search
* Knowledge graph
* Evidence engine
* Entity resolution
* Risk scoring
* Investigation reports
* Natural language interface

---

## Required CockroachDB Features

The MVP should use at least two required hackathon technologies.

Recommended:

* CockroachDB Managed MCP Server
* Distributed Vector Indexing

Optional additions:

* Agent Skills Repository
* ccloud CLI

---

## Required AWS Services

Recommended stack:

* Amazon Bedrock
* Amazon ECS
* Amazon S3
* AWS Lambda

These services satisfy hackathon requirements while matching Atlas's long-term architecture.

---

## MVP Success Criteria

The MVP is successful when a user can:

* investigate a wallet
* ask follow-up questions
* retrieve previous investigations from memory
* understand why Atlas reached its conclusions
* generate an investigation report

Persistent memory should be clearly demonstrated during the demo.

# Final Acceptance Criteria

The Atlas architecture is considered complete when:

* All core platform components have been defined.
* The multi-agent architecture is documented.
* Persistent memory is integrated throughout the platform.
* AI reasoning remains evidence-first and explainable.
* Enterprise security, scalability, and collaboration are established.
* The deployment architecture supports production workloads.
* A phased roadmap exists from MVP to enterprise adoption.
* Atlas has a coherent vision that aligns product strategy, technical architecture, and long-term platform evolution around persistent blockchain intelligence powered by CockroachDB and AWS.

# Next Recommended Deliverables

4. **API Specification** (REST + MCP tools + WebSocket events)
5. **Multi-Agent Prompt Specifications** for every Atlas agent
6. **Frontend UX Wireframes** (dashboard, investigation view, graph explorer, chat interface)
7. **Development Roadmap** with weekly milestones from Day 1 to production launch
8. **Pitch Deck** tailored for the CockroachDB × AWS Hackathon and future investors

These execution documents will convert the Atlas vision into an implementation-ready blueprint.
